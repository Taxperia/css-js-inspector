# Mağaza ekran görüntüleri

Üç dosya da 1280×800 PNG'dir:

- `01-css.png`: eşleşen CSS kuralları.
- `02-javascript.png`: erken kayıt ile yakalanan gerçek showClickCount olay tanımı.
- `03-files.png`: kaynak dosyası listesi ve getirilen CSS metni.

Görüntüler Chrome for Testing 151.0.7922.34'te çalışan 1.1.0 arayüzünden alınmıştır. Aynı deneme oturumundaki gerçek sayfa görünümü (880×800) ile gerçek yan panel görünümü (400×800) yan yana birleştirilmiştir. Metin veya sonuç verisi eklenmemiştir. Örnek sayfa `docs/demo.html` dosyasıdır; gerçek kullanıcı verisi içermez.

İsteğe bağlı izin sonrası senaryosu için yalnızca geçici test kopyasına 127.0.0.1 erişimi eklenmiştir; bu test izni yayımlanan manifestte ve mağaza ZIP'inde bulunmaz. Çalışma kodu ve gösterilen inceleme sonuçları gerçek eklentiden gelir.
